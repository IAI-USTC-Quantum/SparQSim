class pysparq._core.System¶

基类：pybind11_object

Quantum system managing named registers.

The System class provides the foundation for register management. It tracks register names, types, and sizes via a global registry shared by all SparseState instances.

示例

system = System() state = SparseState()

Dict mapping register names to their metadata.

class pysparq._core.SparseState¶

基类：pybind11_object

Sparse quantum state representation.

Stores only non-zero amplitude entries, making it efficient for states with limited superposition. Works with the global System registry.

示例

state = SparseState() AddRegister("q", UnsignedInteger, 4)(state) Hadamard_Int("q")(state)

备注

The sparse representation is memory-efficient but may be slower for dense superposition states.

pysparq._core.Add_UInt_UInt()¶

Add two unsigned integer registers.

Computes: |a⟩|b⟩|0⟩ → |a⟩|b⟩|a+b⟩ (mod 2^n)

参数:

  • input_reg1 -- Name/ID of the first input register (addend).

  • input_reg2 -- Name/ID of the second input register (addend).

  • output_reg -- Name/ID of the output register (accumulates sum).

示例

Add_UInt_UInt("a", "b", "result")(state) # result = a + b

量子门¶

详细用法见 基本量子门、Hadamard 操作 与 QFT。

pysparq._core.Hadamard_Int()¶

Apply Hadamard transform to an integer register.

Creates an equal superposition over all integer values from 0 to 2^n - 1 for the specified number of digits.

参数:

  • reg_in -- Name/ID of the input register.

  • n_digits -- Number of digits (qubits) to apply Hadamard to.

示例

Hadamard_Int("q", 4)(state) # Superpose q over 0..15

pysparq._core.QFT()¶

Quantum Fourier Transform on a register.

Applies the QFT to transform between computational and Fourier bases. Commonly used in phase estimation and Shor's algorithm.

参数:

reg_name -- Name of the register to transform (str) or register ID (int).

示例

QFT("data")(state) # Apply QFT # ... computation ... InverseQFT("data")(state) # Apply inverse QFT

pysparq._core.InverseQFT()¶

Inverse Quantum Fourier Transform on a register.

Applies the inverse QFT to transform from Fourier basis back to computational basis.

参数:

reg_name -- Name of the register (str) or register ID (int).

pysparq._core.QRAMLoad()¶

Load classical data into quantum superposition via QRAM.

Performs the QRAM load operation, creating a superposition where each basis state is entangled with its corresponding data value.

参数:

  • qram -- QRAMCircuit_qutrit instance containing the memory.

  • addr_reg -- Name/ID of the address register.

  • data_reg -- Name/ID of the data register.

示例

qram = QRAMCircuit_qutrit(addr_size=3, data_size=4, memory=data) QRAMLoad(qram, "address", "data")(state)

备注

Use QRAMLoadFast for optimized execution when address distribution is uniform.

pysparq._core.Normalize()¶

Normalize the quantum state.

Ensures the state vector has unit norm by dividing all amplitudes by the total norm. Call after operations that may leave the state unnormalized.

示例

Normalize()(state)
