量子傅里叶变换 (QFT)¶

量子傅里叶变换是众多量子算法的核心组件——如相位估计与 Shor 分解——算法库 中有现成实现。

数学定义¶

量子傅里叶变换定义：

\[QFT|x\rangle = \frac{1}{\sqrt{2^n}} \sum_{y=0}^{2^n-1} e^{2\pi i xy / 2^n} |y\rangle\]

逆量子傅里叶变换：

\[QFT^\dagger|y\rangle = \frac{1}{\sqrt{2^n}} \sum_{x=0}^{2^n-1} e^{-2\pi i xy / 2^n} |x\rangle\]

QFT¶

class pysparq.QFT¶

Quantum Fourier Transform on a register.

Applies the QFT to transform between computational and Fourier bases. Commonly used in phase estimation and Shor's algorithm.

参数:

reg_name -- Name of the register to transform (str) or register ID (int).

示例

QFT("data")(state) # Apply QFT # ... computation ... InverseQFT("data")(state) # Apply inverse QFT

dag(self: pysparq._core.QFT, state: pysparq._core.SparseState) → None¶

Apply the adjoint (inverse) of this operation.

参数:

state -- The quantum state to operate on.

Note: Only available for self-adjoint operators.

操作: 对整数寄存器执行量子傅里叶变换

类型约束: UnsignedInteger 或 SignedInteger

位约束: 寄存器大小决定变换维度

import pysparq as ps

ps.System.clear()

# 4 比特寄存器
ps.System.add_register("q", ps.UnsignedInteger, 4)

state = ps.SparseState()

# 初始化为基态 |1⟩
ps.Init_Unsafe("q", 1)(state)

print("初始状态:")
ps.pprint(state)
# |q=1⟩ : (1+0j)

# 应用 QFT
op = ps.QFT("q")
op(state)

print("\nQFT 后:")
ps.pprint(state)
# 产生相位均匀分布的叠加态

# 撤销（逆变换）
op.dag(state)

周期发现（Shor 算法）¶

import pysparq as ps
import numpy as np

ps.System.clear()

# 相位寄存器
n_bits = 8
ps.System.add_register("phase", ps.UnsignedInteger, n_bits)

state = ps.SparseState()

# 模拟相位估计结果（假设周期 r = 5）

# 应用逆 QFT 解析周期
ps.InverseQFT("phase")(state)

性能考虑¶

  • 基态数量: QFT 作用于叠加态时，会产生 \(2^n\) 个基态

  • 内存限制: 当 n 较大时（如 n > 20），可能导致内存问题

  • 稀疏优化: PySparQ 只存储非零振幅基态，对于某些输入可能高效

备注

对于非完整的叠加态，QFT 的稀疏实现可能比全态模拟更高效。

实际示例¶

完整 QFT + InverseQFT 循环¶

import pysparq as ps
import numpy as np

ps.System.clear()

n = 3
ps.System.add_register("q", ps.UnsignedInteger, n)

state = ps.SparseState()

# 初始值
initial_value = 5
ps.Init_Unsafe("q", initial_value)(state)

print("初始状态:")
ps.pprint(state)

# QFT
ps.QFT("q")(state)
print("\nQFT 后:")
ps.pprint(state)

# InverseQFT
ps.InverseQFT("q")(state)
print("\nInverseQFT 后:")
ps.pprint(state)
# 恢复到 |q=5⟩
