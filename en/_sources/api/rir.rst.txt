RIR Interpreter API Reference
=============================

This module interprets and executes RIR JSON documents from QECC.Lang directly on PySparQ sparse states, making PySparQ a native backend for RIR. The concept and usage guide is :doc:`RIR Interpretive Execution </guide/rir>`.
